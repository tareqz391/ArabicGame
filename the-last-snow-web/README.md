# The Last Snow — الثلج الأخير (three.js)

A cinematic 2.5D winter mystery for Android Chrome (landscape, touch). Story, chapters and
systems: [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md). Asset sources & licences:
[`docs/ASSETS.md`](docs/ASSETS.md). The earlier Unity attempt is kept in `../Unity_Backup`.

## What is playable now (Chapter 1, scene 1)
1. Intro cutscene in the night train (date card, waking up, the photo of Adam & Elias, brakes,
   "Last stop… Norville", the door opens).
2. Norville station: stopped clock (11:59), a memory triggered by the timetable, chalk marks
   only visible with the flashlight, battery under a tarp, generator, pushable crate, climbing,
   the control panel lever, lights coming on, the gate opening, the child's call, end card.
3. Systems: AR/EN (switchable), auto-save checkpoints (localStorage), cold meter (warmth near
   lamps/generator), flashlight, push/pull, carry, mantle, footprints, GPU snowfall, fog,
   bloom/vignette/grain, adaptive resolution, procedural audio.

**Not final:** all models are stylised prototypes generated by script (see ASSETS.md). Real-device
performance on Android has not been measured yet (tests ran with software WebGL).

## Controls
- Touch: left half = joystick (push further to run; up/down = move in depth), buttons:
  Jump (also climbs ledges), Use, Crouch, Light, Pause.
- Keyboard: WASD/arrows, Shift run, Space jump, E use, C crouch, F flashlight, Esc pause.

## Develop
```
npm install
npm run dev              # http://localhost:5173
npm run build            # dist/ (GLB models)
npm run build:artifact   # dist/page.html + glTF JSON models for claude.ai Artifact hosting
```
Regenerate models (needs the `bpy` module, Python 3.11): `npm run assets`.
Automated play-through (needs `npm run preview` running): `npm test`.

## Layout
```
src/engine   Collision (AABB), Input (touch + keys), Renderer (post FX), Assets (GLTF)
src/game     Game loop, Player, CameraRig, Interact (+Pushable), State (flags/save), i18n, Sound
src/fx       Snow, Footprints, LightPool, canvas Textures
src/levels   Station.js (layout, puzzle, story script)
src/ui       DOM HUD/menus/subtitles/photo card + CSS
tools/blender  asset scripts;  tools/test  Playwright scenarios
```
