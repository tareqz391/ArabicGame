# 🎬 استوديو المونتاج

محرر فيديو متكامل يعمل بالكامل داخل المتصفح، بدون خادم وبدون تثبيت. افتح `editor/index.html` (أو `/editor/` على GitHub Pages).

## المميزات
- **استيراد** فيديو وصوت وصور (زر أو سحب وإفلات)، مع حفظ تلقائي للمشروع والملفات في المتصفح (IndexedDB).
- **خط زمني متعدد المسارات**: مسارات فيديو وصوت غير محدودة، سحب ونقل بين المسارات، قص من الأطراف، تقسيم، تكرار، نسخ ولصق، حذف وسد الفراغ، التقاط مغناطيسي، تكبير وتصغير، إخفاء/كتم/قفل المسارات.
- **صور مصغّرة وموجات صوتية** للمقاطع.
- **نصوص عربية احترافية**: خطوط عربية (Cairo, Tajawal, Amiri, Reem Kufi, Lalezar, Changa, Aref Ruqaa)، إطار، ظل، توهج، خلفية، و8 أنماط جاهزة.
- **التحويل**: الموضع، الحجم، الدوران، الشفافية، القلب، ملاءمة/تعبئة، تأثير كين برنز — مع السحب المباشر داخل المعاينة.
- **الفلاتر وتصحيح الألوان**: سطوع، تباين، تشبع، تدرج لوني، ضبابية، أبيض وأسود، بني، عكس + 11 فلتراً جاهزاً.
- **الحركات والانتقالات**: تلاشي، انزلاق (4 اتجاهات)، تكبير، تصغير، دوران، ضبابية، آلة كاتبة — للدخول والخروج.
- **الصوت**: مستوى صوت حتى 200%، كتم، تلاشي دخول/خروج، تغيير السرعة (0.25x – 4x).
- **أبعاد المشروع**: 16:9، 9:16 (ريلز/تيك توك)، 1:1، 4:5، 21:9، حتى 4K.
- **التصدير** إلى MP4 أو WebM بجودة قابلة للاختيار (المشروع كاملاً أو مقطع محدد)، وحفظ لقطة PNG.
- **تراجع/إعادة** واختصارات لوحة مفاتيح كاملة (زر ⌨️ داخل التطبيق).

> التصدير يتم بالسرعة الحقيقية داخل المتصفح؛ يُفضّل استخدام Chrome أو Edge.
