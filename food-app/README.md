# 🍔 طلباتي - تطبيق طلبات الطعام

تطبيق متكامل لطلب الطعام باللغة العربية، يتكون من:

- **واجهة الزبائن** (`/`) لتصفح المطاعم وطلب الأكل ومتابعة الطلب.
- **لوحة تحكم المدير** (`/admin`) لإضافة المطاعم والقوائم وإدارة الطلبات.

لا يحتاج التطبيق إلى أي مكتبات خارجية، يكفي تثبيت **Node.js 18 أو أحدث**.

## ▶️ التشغيل

```bash
cd food-app
node server.js
```

ثم افتح:

| الصفحة | الرابط |
|---|---|
| تطبيق الزبائن | http://localhost:3000 |
| لوحة التحكم | http://localhost:3000/admin |

**حساب المدير الافتراضي:** `admin@food.com` / `admin123`
⚠️ غيّر كلمة المرور من صفحة **الإعدادات** في لوحة التحكم مباشرة.

عند أول تشغيل يُنشأ ملف `data/db.json` وفيه مطاعم وأصناف تجريبية، وتُحفظ الصور المرفوعة في `data/uploads/`.
لإعادة التطبيق لحالته الأولى احذف مجلد `data`.

متغيرات اختيارية: `PORT` (المنفذ) و`DATA_DIR` (مكان حفظ البيانات).

## 📲 تطبيقات الجوال (تطبيق للزبائن + تطبيق لوحة التحكم)

يوجد تطبيقان منفصلان، لكل واحد اسمه وأيقونته:

| التطبيق | الاسم على الجوال | يفتح |
|---|---|---|
| 🍔 تطبيق الزبائن | طلباتي | `السيرفر/` |
| 🛠️ تطبيق الإدارة | طلباتي - الإدارة | `السيرفر/admin` |

> التطبيقات تتصل بالسيرفر، لذلك **ارفع السيرفر على الإنترنت أولاً** (انظر "الرفع على الإنترنت" بالأسفل).

### أندرويد (ملفات APK) — تُبنى تلقائياً على GitHub
1. افتح الملف `food-app/mobile/server-url.txt` على GitHub، واضغط ✏️، واكتب رابط السيرفر (مثل `https://talabati.onrender.com`)، ثم احفظ (Commit).
2. سيبدأ البناء تلقائياً في تبويب **Actions** (يستغرق حوالي 5 دقائق).
3. عند الانتهاء ستجد في صفحة **Releases** بالمستودع ملفين:
   `talabati-customer.apk` و`talabati-admin.apk`.
4. نزّل الملف على جوال أندرويد وافتحه (اسمح بـ"التثبيت من مصادر غير معروفة").

يمكنك أيضاً تشغيل البناء يدوياً: **Actions ← بناء تطبيقات أندرويد ← Run workflow**.

للبناء على جهازك (يتطلب Android Studio وJava 21):
```bash
./mobile/build-android.sh customer https://your-server.com
./mobile/build-android.sh admin    https://your-server.com
```

### آيفون + أندرويد بدون APK (تطبيق ويب قابل للتثبيت)
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.
- **أندرويد (Chrome):** افتح الرابط ← ⋮ ← **تثبيت التطبيق**.

افعل ذلك مرة للرابط `/` (الزبائن)، ومرة للرابط `/admin` (الإدارة). يظهر كل واحد كتطبيق بأيقونته، ويفتح بشاشة كاملة.

### النشر في المتاجر
- **Google Play:** يحتاج حساب مطوّر (25$ مرة واحدة) وتوقيع التطبيق بنسخة Release (ملف AAB).
- **App Store:** يحتاج جهاز Mac وحساب Apple Developer (99$ سنوياً).

## 🌐 الرفع على الإنترنت (Render.com)
1. سجّل في https://render.com بحساب GitHub.
2. اختر **New ← Blueprint**، ثم اختر المستودع؛ سيقرأ ملف `render.yaml` تلقائياً.
   أو **New ← Web Service** مع الإعدادات: Root Directory = `food-app`، Start Command = `node server.js`.
3. ستحصل على رابط مثل `https://talabati.onrender.com`.

⚠️ الخطة المجانية في Render تمسح البيانات عند إعادة التشغيل. لحفظ دائم أضف Persistent Disk واضبط متغير البيئة `DATA_DIR` على مساره.

## 📱 خصائص واجهة الزبون

- تسجيل حساب وتسجيل الدخول.
- عرض المطاعم مع حالة المطعم (مفتوح أو مغلق حسب أوقات الدوام)، التقييم، مدة التوصيل، رسوم التوصيل، والحد الأدنى للطلب.
- البحث، والتصفية حسب التصنيف، والترتيب (الأكثر طلباً، الأعلى تقييماً، أقل رسوم توصيل، الأسرع توصيلاً).
- قائمة المطعم مقسمة إلى أقسام، مع الأصناف المميزة 🔥 وتمييز الأصناف غير المتوفرة.
- إضافات لكل صنف (جبنة إضافية، حجم كبير...)، والكمية، وملاحظات خاصة.
- سلة مشتريات: تعديل الكميات، كود خصم، رسوم التوصيل، الضريبة، والتنبيه عند عدم الوصول للحد الأدنى للطلب.
- إتمام الطلب: اختيار عنوان محفوظ أو إضافة عنوان جديد، رقم الهاتف، ملاحظات، والدفع نقداً أو بالبطاقة.
- تتبع الطلب لحظياً (بانتظار التأكيد ← تم التأكيد ← قيد التحضير ← في الطريق ← تم التوصيل)، ويتحدث تلقائياً.
- إلغاء الطلب قبل أن يؤكده المطعم.
- تقييم المطعم بالنجوم والتعليق بعد التوصيل، وتظهر التقييمات لباقي الزبائن.
- سجل الطلبات، وزر "إعادة الطلب".
- المطاعم المفضلة ❤️.
- صفحة الحساب: تعديل البيانات، إدارة العناوين، وتغيير كلمة المرور.
- تصميم متجاوب للجوال مع شريط تنقل سفلي.

## 🛠️ خصائص لوحة التحكم

- **الإحصائيات:** طلبات ومبيعات اليوم، إجمالي الإيرادات، متوسط قيمة الطلب، رسم بياني لمبيعات آخر 7 أيام، أكثر المطاعم والأصناف طلباً، وأحدث الطلبات.
- **الطلبات:** تصفية حسب الحالة أو المطعم، والبحث. تغيير حالة الطلب بضغطة زر، والإلغاء مع ذكر السبب، وطباعة الفاتورة 🖨.
  - **تنبيه صوتي 🔔** عند وصول طلب جديد، مع عداد للطلبات المعلقة.
- **المطاعم:** إضافة وتعديل وحذف المطاعم، رفع الصور، رسوم التوصيل، الحد الأدنى للطلب، مدة التوصيل، أوقات الدوام، فتح وإغلاق المطعم أو إخفاؤه بضغطة واحدة.
- **قوائم الطعام:** إضافة الأصناف مع السعر والوصف والصورة والقسم والإضافات، مع تحديد الصنف كمتوفر أو مميز.
- **التصنيفات:** إدارة تصنيفات المطاعم (الاسم والأيقونة والترتيب).
- **كوبونات الخصم:** نسبة مئوية (مع حد أقصى للخصم)، أو مبلغ ثابت، أو توصيل مجاني. يمكن تحديد حد أدنى للطلب، وعدد مرات الاستخدام، وتاريخ الانتهاء، أو تخصيص الكوبون لمطعم معين.
- **المستخدمون:** عرض الزبائن مع عدد طلباتهم ومجموع مشترياتهم، حظر المستخدمين، أو ترقيتهم إلى مدير.
- **الإعدادات:** اسم التطبيق، العملة، نسبة الضريبة، رقم خدمة العملاء، وتغيير كلمة المرور.

## 🔒 الأمان

- كلمات المرور مشفرة بخوارزمية `scrypt`.
- الأسعار والخصومات تُحسب على الخادم فقط، فلا يستطيع الزبون التلاعب بالسعر.
- واجهات المدير محمية ولا يمكن لأي زبون الوصول إليها.
- يتم التحقق من صحة جميع المدخلات.

## 🚀 قبل الإطلاق الفعلي

- **الدفع بالبطاقة حالياً تجريبي:** اربطه ببوابة دفع حقيقية مثل Stripe أو HyperPay أو PayTabs.
- يمكن استبدال ملف JSON بقاعدة بيانات مثل PostgreSQL أو MongoDB عند زيادة عدد الطلبات.
- شغّل التطبيق خلف HTTPS، مثلاً عبر Nginx أو Render أو Railway.
